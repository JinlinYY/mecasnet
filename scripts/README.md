# Experiment scripts

The experiment code is organized by the article rather than by implementation
type. Start at [experiments/README.md](experiments/README.md), then choose the
main-manuscript section or Supplementary Note that you want to inspect.

Run commands from the repository root after installing the package in editable
mode. Write generated artifacts under `runs/`; do not place protected datasets,
checkpoints, or firm identifiers under `scripts/`.
